# Guided app contracts

These are installable Manifest examples generated by App Studio's shared assistant model. They contain no secrets. Import through Developers, save a version and install it into a private sandbox. See [guide and security contracts](../../../docs/app-assistants.md).

| File | Purpose |
| --- | --- |
| frontend.json | Public product-detail cards with an owned product reference and private editing tab. |
| admin.json | New product editor tab with revision-bound fields. |
| combined.json | Private product tab plus explicit public product-detail data. |
| product_general.json | Additional section inside product general settings. |
| customer.json | Private customer-bound fields and translated choice list. |
| order.json | Private order-bound fields and choice list. |
| payment.json | Native settings and external initiate/capture/refund contracts. |
| shipping.json | Native settings and external label/tracking contracts. |
| integration.json | ERP-style synchronize service action and order events. |
| event.json | External event consumer plus a Flow-enabled service action. |
| webhook.json | Signed incoming webhook emits a typed event for rules/flows. |
| scheduled.json | UTC scheduled emit task; requires no separate app timer process. |

Payment/shipping/integration/event examples require an operator-deployed service configured through APP_SERVICES. They do not implement the provider. Webhooks require APP_WEBHOOK_KEYS. Cron and external ingress are disabled for private sandboxes; real behavior is verified in disposable live test shops by scripts/app_assistants.py. New examples default to MCP off, with explicit action team rights. Public customer/order references are forbidden.
