# Care Studio example

A native visual app: tenant-owned translated care-guide records, an admin table/form module, public product-detail cards, HTTP routes, MCP tools, AI grounding and Flow Builder-enabled saves. English, German, French and Spanish labels are included; enabled shop languages remain dynamic.

Import `manifest.json` through App Studio, target a private sandbox, install the reviewed immutable build and test actual records. Publish the package explicitly; release selected records separately. No extra app server is needed.

The example intentionally permits public guide reads. New App Studio drafts start private. Product-page guides are not automatically filtered by product ID. See `docs/app-studio.md` for behavior, boundaries and a step-by-step workflow.
