# Responsibilities

PrivacyProvider validates server receipts and controls a keyboard-accessible consent dialog. CheckoutLegal supplies an explicit acknowledgement committed immediately before purchase. LegalDocument renders escaped inherited shop documents, ProductSafety publishes factual product disclosures, and ConsumerRequestForm captures two-step declarations without granting access to an order.

Regression coverage: frontend/tests/unit/legal-privacy.test.tsx and scripts/legal_privacy.py; connected provider tests in scripts/email_tests.py. See docs/european-operation.md for legal sources, configuration and proof limits.
