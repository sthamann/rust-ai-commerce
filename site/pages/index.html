A suggestion becomes a change only after approval.

Recorded with the real local model and a synthetic shop. Waiting time is shortened; this is not a speed benchmark. No real payment occurs.

The local model proposes a lamp price of EUR 69.90 instead of EUR 74.90. Before approval, the current shop price remains EUR 74.90. After the merchant approves, the storefront displays EUR 69.90 and stock remains unchanged.

The authority boundary

From a suggestion to an approved change.

  1. Ask

    A merchant asks the assistant for a catalog change.

  2. Inspect

    The stored proposal shows the exact changes and current evidence.

  3. Approve

    An authorized merchant explicitly approves that proposal.

  4. Apply

    The Rust core checks revisions and updates the owning shop.

Model text cannot grant access. A readable summary does not replace inspecting the actual proposal.

Common questions

What is Rust AI Commerce?

Rust AI Commerce is an MIT-licensed ecommerce prototype for exploring merchant-approved AI operations, local models and agent commerce protocols. Its Rust core shares deterministic commerce operations across browser, MCP and UCP adapters. It is also a laboratory for selected Shopware behavior ports.

Do I need an LLM to try it?

No. You can start the storefront, merchant workspace, cart and simulated checkout without downloading a model. AI planning needs a configured local or cloud model; semantic indexing needs an embedding service.

Is it a Shopware replacement?

No complete drop-in replacement is claimed. The project ports selected original behavior and implements native prototype equivalents. The feature matrix identifies missing Shopware functionality and differences in schemas and lifecycle behavior.

Does it process real payments?

No real money is charged. Payments are simulated, manually recorded or PayPal Sandbox. The Sandbox adapter is checked with local contract fixtures; no live Sandbox transaction or live-money payment processing is claimed. Carrier integration remains missing.

Can I use it with Claude Desktop or ChatGPT?

The documented local stdio bridge supports compatible MCP clients such as Claude Desktop. Hosted clients need a reachable secure endpoint and their own account setup. The project does not configure external accounts or provide a production OAuth authorization server.
